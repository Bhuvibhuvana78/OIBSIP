
# Number Guessing Game

## Description
A simple Java console game where the player guesses a random number between 1 and 100.

## Features
- Random number generation
- Too High and Too Low hints
- Maximum 7 attempts
- Win and lose messages
- Play Again option
- Score tracking

## Technologies Used
- Java
- Scanner
- Random

## How to Run
Compile the program:
javac NumberGuessingGame.java

Run the program:
java NumberGuessingGame
